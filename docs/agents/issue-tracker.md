# Issue tracker: Local Markdown

Issues and specs for this repository live as Markdown files in `.scratch/` until the user explicitly authorizes an external tracker.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`
- The normative spec is `.scratch/<feature-slug>/spec.md`
- Implementation issues are individual files in `.scratch/<feature-slug>/issues/<NN>-<slug>.md`
- A `Status:` line records workflow state near the top of each issue
- Conversation history, when needed, is appended under `## Comments`

## External publication

Publishing a spec or issue to GitHub, GitLab, or another external service is a separate side effect and requires explicit approval. Creating a local file is not permission to create a remote issue.
