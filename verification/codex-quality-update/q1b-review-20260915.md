# Q1b independent review — 2026-09-15

Scope: Q1b design-admission extraction only. Compared current controller code
with `verification/codex-quality-update/q1a-accepted/`, inspected the new
service and Q1b evidence, and used a temporary public CLI fixture. No source,
test, configuration, or existing evidence was modified.

## Finding

### Important — ordinary relative receipt paths have changed from CLI-CWD-relative to repository-relative

`Controller.acquireDesignReceipt` unconditionally calls
`resolve(repositoryRoot, reference)` before passing the result to `readReceipt`.
Before Q1b, an ordinary `transition --to design-approved` passed the supplied
reference directly to `readReceipt`, which calls `resolve(path)` and therefore
resolves a relative path from the invoking CLI process working directory.

The new behavior changes a public contract even after the containment repair:
ordinary transition receipts may be readable outside the repository, and a
relative reference in the caller's directory now instead points beneath
`--repo`. Fresh-claim receipt sources are different: their old and current
paths are resolved from the repository root and then realpath/containment
checked.

Reproduced using the built public CLI from a caller directory distinct from a
temporary Standard repository. After valid initialization, route, approval and
design-review, a valid `caller/receipt.json` supplied as `--receipt
receipt.json` returned exit 2 / `SCHEMA_INVALID` with ENOENT for
`<repo>/receipt.json`. The Q1a controller would read `caller/receipt.json`.

Repair scope: keep repository-root resolution plus realpath/containment for
fresh claims only. The ordinary transition acquisition path must retain the
existing `readReceipt` reference resolution behavior (while still capturing
the bytes once for the service object). Add a public regression with a distinct
CLI cwd, `--repo`, and a valid relative receipt outside that repository.

## Other review observations

The service otherwise has explicit inputs, owns the four intended decisions,
does not acquire locks or mutate journals, and leaves prepared-time proof,
receipt-byte parsing, exact-operation comparison and recovery checks in
`Controller.validateClaimBatch`. Its lazy receipt callback preserves the
preexisting authority/source-drift checks before receipt acquisition.

## Assessment

Not ready for Q2. Repair the Important ordinary-transition path regression,
run its focused public regression, then request a narrow re-review.
